# Nera Detail

A modern, responsive website for **Nera Detail**, a professional car detailing company.  
The site is designed with UX best practices, supports light/dark themes, and is optimized for desktops, tablets, and mobile devices.

## 🚀 Features
- Responsive design (desktop, tablet, mobile)
- Light/Dark theme support
- Clean UI with modern UX principles (based on [Laws of UX](https://lawsofux.com/))
- Pages:
  - **Home** – Hero section, trust signals, CTA
  - **Services** – Detailing packages & special services
  - **Photos** – Portfolio gallery with before/after
  - **Prices** – Transparent pricing table with FAQs
  - **Contact** – Form, map, and contact info
- Built with accessibility and performance in mind

## 🎨 Tech Stack
- **React + TailwindCSS** (UI components & styling)
- **Material UI Icons** (modern, consistent iconography)
- **Framer Motion** (smooth animations)
- **Responsive Grid Layout** for flexible content
